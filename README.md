# 求职工作台1.0

一个面向香港实习和内地校招的本机工作台。只记录你自己的求职进度：发现岗位、辅助填表、追踪投递，最后把需要你行动的事放到首页。你的简历资料在本机，不会被自动发给招聘方。

本仓库的 1.0 版整合了原 v1.1.13 简体演示基线、资料编辑页更新和浏览器扩展更新。**1.0.2** 支持从岗位收藏到面试改期，也支持从资料草稿到分条填表。[版本说明](docs/releases/1.0.2.md) · [下载 1.0.2](https://github.com/yirenyinjiuzui/Jobwork/releases/tag/v1.0.2)

岗位搜索已包含 [PR #1](https://github.com/yirenyinjiuzui/Jobwork/pull/1)。公司、岗位、地点和编号可以组合搜索，词序、大小写、全角和连续空格均可混用。原有的资料保存与导出、逐条填表、测评待办、面试日历和岗位收藏修复均已包含。正式版提供完整包、模块包和校验清单。[完整包与模块包](https://github.com/yirenyinjiuzui/Jobwork/releases/tag/v1.0.2)

## Windows 两步打开

首次安装、ZIP 下载失败或启动出错，请先看 [Windows 安装与 TXT 恢复](docs/WINDOWS.md)。启动器会检查 Python 3.11+ 和主要文件是否完整；无需 Node、pip 或管理员权限。

1. 安装 Python 3.11 或更新版本（已有 Python 3.13 可直接用）。把压缩包完整解压到一个容易找到的位置，例如 `D:\求职工作台`。
2. 双击 **`start-windows.cmd`**。保留启动窗口，浏览器会打开 **http://127.0.0.1:8765/**。如果没有自动打开，自己在地址栏输入该地址。

无需 `pip install`。普通启动可以断网使用；联网检查官方职位板才需要互联网。PowerShell 或 macOS/Linux 也可以运行 `python server.py`（部分系统使用 `python3`）。端口被其他程序使用时可用 `py -3 server.py --port 8766`，页面地址同步改成 8766。

### 从旧工作台迁移

把本版解压到**不同文件夹**。关掉旧版的启动窗口，备份旧版的 `data` 文件夹，再把该文件夹复制到新版 `job-workbench` 内，最后启动新版。新版会保留既有记录并补齐简历版本字段。如果旧版还没启动过，不需要迁移。不要同时运行两个版本访问同一个数据库。扩展可在浏览器扩展页移除旧版再加载新版（旧版扩展不保存个人资料）。

### 先试用，再开始记录真实资料

**独立演示库：** 在 PowerShell 里运行 `py -3 server.py --data data/demo.sqlite3`。点首页「载入演示记录」。之后关闭运行窗口，双击默认启动文件即可回到独立的空白正式库。演示记录全是虚构的；想从头试，可以换一个新的演示库文件名。

- **公司与岗位**：对「示例招聘」点三次「检查」，依次看到初始基线、新岗位、重新开放。选「香港实习」或「内地校招」试筛选；把某岗位存进投递台账。
- **投递追踪**：使用 [示例通知](docs/sample-notices.txt) 导入改期或延期通知。识别本身不会修改台账；核对匹配的岗位、时间和状态，再确认更新。旧通知留在时间线。同公司不同岗位编号不会合并。
- **资料与填表**：用示例姓名、邮箱创建测试资料，导出 JSON，在下文的本地演示表单试填。不必在试用时输入真实资料。

## 1 · 公司库、开招提醒与岗位筛选

在「公司与岗位」添加公司和官方招聘入口。对使用 **Greenhouse / Lever / Ashby / SmartRecruiters** 的公司添加公开招聘板链接或板块代号（[格式与官方文档](docs/SOURCES.md)）。第一次成功检查只建立基线；之后发现新增、重新开放时在首页提醒。招聘板下架与「你被拒绝」是两回事；公开源读取失败也不会把既有岗位当成关闭。

- 招聘板有明确毕业条件、入职条件或截止日期时显示；缺失的条件到原链接核对，不猜。
- 自建官网、BOSS 直聘、Workday 目前可手动录入岗位和链接，但不会自动监测，也不会代登账号。不要把「已收藏」当成「开招提醒已启用」。
- 默认网页服务开启后每 30 分钟检查真实招聘源。关闭启动窗口、电脑睡眠或断网，检查会暂停。浏览器即使关闭，若服务仍在运行，应用内提醒仍会写入数据库，下次打开可看。首页可由你授权开启桌面提醒（仅在本页打开时有效），没有手机推送。
- 想让电脑开机时不依赖网页进程，可在 **Windows 任务计划程序** 自行添加一项任务，按需重复执行 `check-sources-windows.cmd`。它只检查一次、保存提醒、退出。不要和网页服务的定时检查重复跑；任务计划和网页服务需使用同一个数据文件。也可手动执行 `py -3 server.py --check`。程序不会自动安装任何后台任务。

### 从浏览器收藏职位草稿

加载本版扩展后，在职位详情页点「识别当前岗位」。能识别的职位信息先在扩展里预览。点击「在工作台核对（不保存）」后，字段进入本机「手动录入岗位」表，不会直接保存。核对公司、岗位编号、地点和截止日再录入。扩展不扫描职位列表，不读取背景标签页，不登录、不抓受限页面。若页面没有可用职位信息，仍可手动录入标题和分享链接。扩展的端口默认是 8765，可改成你启动时指定的端口。

## 2 · 本地资料与辅助填表

1. 在「资料与填表」选择简历，点击「解析并预览」。支持 UTF-8 TXT、DOCX 和有文字层的 PDF，单个文件最大 5 MiB。PDF 需要本机 PATH 中的 `pdftotext`。解析在本机完成。勾选需要的字段或整条经历，加入草稿，再用「内容导航」逐栏核对。已有字段保留原值。有未保存的改动时，点击「保存并导出填表资料 JSON」即可保存并下载。若另一页先保存，当前页保留草稿，可打开最新版对照。也可直接手动编辑，性别、学历等字段提供下拉选项。
2. 打开 Chrome 的 `chrome://extensions/` 或 Edge 的 `edge://extensions/`，开启开发人员模式，点「加载已解压的扩展程序」，选择解压目录中的 **`extension`** 文件夹。可以把扩展固定在工具栏。
3. 先打开本地应用里的「本地练习表单」，或进入你已打开的正常 HTTPS 职位申请表。打开扩展并导入资料 JSON，点「扫描当前网页」。扩展仅在当前页请求被允许的权限，不会自动访问其他网页。
4. 逐项勾选或一次选中剩余可选字段，核对拟填值并确认后再填写。复扫时，可比对的已有值会显示与资料是否一致。遇到性别、学历和政治面貌的原生单选下拉框，预览列出唯一对应的网页选项。扩展保留已有选择。自绘下拉、多选、跨站 iframe、资格承诺、证件和附件由你手动处理。页面变化后需重新扫描。扩展只写入经确认的字段，提交由你操作。

**截图 OCR 是可选的**：如果本机装了 Tesseract 且已添加到 PATH（或设置环境变量 `TESSERACT_CMD` 指向它），就在工作台的资料页选择语言和 PNG/JPEG 截图，扫描后可把结果贴到扩展的文字辅助区。中英文混合需另装 `chi_sim` 或 `chi_tra` 数据与 `eng`。识别在本机完成；截图文字只作手动参考，不会据此猜测网页坐标、填敏感项或自动提交。不装 OCR 也能用正常网页的字段识别。

## 3 · 投递与进度

- 每次提交后，在台账将对应岗位从「已收藏」标为「已投递」或「待反馈」。同一公司不同岗位仍各记一笔，尽量使用岗位编号；无编号时按公司、岗位名称与地点区分。
- 粘贴招聘通知或导入本机 `.eml`。可以先提供公司、岗位编号和收件时间帮助识别。明确状态可识别为网测、面试、Offer、终止等；模糊或时间相对的通知请人工核对。`.eml` 的时间取自邮件 Date 头，未必是实际收件时间。
- 可在列表和看板之间切换，用状态列查看进度。编辑某条记录可以写入该岗位实际使用的简历版本；不会自动上传或更换简历。
- 有面试或截止日的记录可以导出 `.ics`，手动导入 Outlook 或其他日历。推算时间会标明，只有日期的事件按全天占位。日历不是实时同步，改期请重新导出并检查旧事件。
- 更晚的改期或延期更新原记录；过时通知或不应回退的状态只保留在历史。没收到结果就是待反馈，不猜测拒绝。首页优先列 3 项下一步；表格可筛选，台账可以 CSV 导出。
- **不会读取真实邮箱**，也无法读取登录后招聘后台的内部状态。真实邮件走复制粘贴或导出 `.eml`；表单由你亲自核对后提交。对「网测后没消息」之类情况，只能保留可证实的状态。

## 数据与备份

默认数据库在 `data/workbench.sqlite3`，只绑定本机回环地址，不需要账户，不应对外网开放。数据、导出的 JSON、CSV 都是本地明文，请勿上传公开仓库或共享设备；不在资料库保存密码、验证码或证件号。备份前退出所有工作台和招聘源检查，复制完整 `data` 目录即可。可用 `--data` 选择自己的数据库路径。扩展导入的资料驻留在打开的弹窗，关闭弹窗后需重新导入。
