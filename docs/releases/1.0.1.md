# 求职工作台 1.0.1

本版增加与 Codex 四个功能对话一致的模块目录和分类下载包。日常使用下载 `job-workbench-v1.0.1.zip`。模块包用于单独查看或维护某个功能，包含相关源码和验收资料。

| 功能分类 | 下载包标识 |
| --- | --- |
| 岗位发现与开招提醒 | `discovery` |
| 简历导入与个人资料 | `profile` |
| 浏览器扩展与网申填表 | `extension` |
| 投递追踪与待办 | `tracking` |

**浏览器扩展与网申填表**增加双记录实填验收。在本地练习页从原生扩展弹窗选中两项，第 1 条工作经历的工作单位写入“示例能源装备厂”，第 2 条的工作岗位写入“测试工程师”。逐项比对 52 个控件，只有这两项发生变化，提交事件为 0。[查看实填截图](https://github.com/yirenyinjiuzui/Jobwork/blob/v1.0.1/docs/demo/work-experience-two-fields.png)

发布附件同时提供完整包的 TXT 恢复副本和 SHA-256 校验清单。
