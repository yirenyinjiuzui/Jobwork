# 求职工作台 1.0.2

本版整合四个功能模块。下载完整包后解压到新目录，通过本机演示库试用。[下载正式版](https://github.com/yirenyinjiuzui/Jobwork/releases/tag/v1.0.2)

- 岗位和投递都支持跨字段多关键词搜索。多地点岗位会同时考虑香港与内地的地点信息。
- 投递列表和看板可逐批查看超过 150 条的记录。CSV 单独导出实际投递时间，同一天的测评优先展示有明确时刻的截止时间。
- 在个人资料草稿里可逐项审阅 Agent 提出的单字段建议，再决定是否采用和保存。

## 第一批 · 从岗位收藏到面试改期

| 模块 | 可以试什么 | 核对结果 |
| --- | --- | --- |
| 岗位发现与开招提醒 | 收藏 A 并标记已投递，移除来源，再收藏 B 两次 | A 的状态和历史保留，B 单独一笔。升级时会核对旧岗位链接及资料，无法核对的台账保留。 |
| 投递追踪与待办 | 同一岗位录入编号不同的 A、B 测评，再粘贴 A 的完成回执 | 单独确认后只结束 A，首页显示 B 的截止。缺少可靠编号的回执经复核只写入历史。 |
| 投递追踪与待办 | 从已有申请截止的投递导入面试邀请，再导入改期并下载日历 | 面试按新场次排列。通知中明确写出的面试回复期限单独记录，只有日期的期限按全天导出。 |

### 岗位搜索

[PR #1](https://github.com/yirenyinjiuzui/Jobwork/pull/1) 已并入预览。搜索要求每个词都能在同一岗位的公司、岗位名、地点或编号中找到，各词可以位于不同字段。虚构岗位「示例科技 / AI Engineer Intern / 香港 / TEST-101」可以用 `香港 AI 示例` 或 `ＴＥＳＴ-１０１` 找到。

已在 Windows Edge 158 的独立无头实例中核对换序、多空格、大小写、全角编号、地区筛选、只看开放岗位以及清空后的实际岗位编号。演练使用独立数据库。

## 第二批 · 从资料草稿到练习填表

| 模块 | 可以试什么 | 核对结果 |
| --- | --- | --- |
| 简历导入与个人资料 | 两个标签页分别修改一份资料，再保存和导出 | 旧页保留草稿，可另开最新版对照。切换页面或刷新前会提示，有改动时用「保存并导出」下载眼前的资料。 |
| 浏览器扩展与网申填表 | 在本地练习表单先填两项，重扫并选中剩余可填项 | 可比对的已有项标出是否一致，保持锁定。可一次勾选、逐项取消，再单独确认填写。演示共 7 条、17 项。 |

用包内 `extension/demo-profile-toolbar-17.json` 试分条填表。第一次勾选工作经历第 1 条的单位“示例能源装备厂”和第 2 条的岗位“测试工程师”。七条记录包括两条工作经历、一条校园经历、两条获奖和两条语言记录。练习在核对后结束，提交由使用者决定。

旧版已误改的记录需结合原通知核对。没有证据的旧截止日期不会自动认定为面试回复期限。预览验收使用本机虚构数据；真实招聘网站的表单各不相同。

在独立 Chrome 中先写入两项，复扫锁定原值，再勾选并填写其余 15 项。读回 17 项均对应预期记录，另 35 个控件保持原值，提交事件为 0。[查看七条记录的实填截图](https://github.com/yirenyinjiuzui/Jobwork/blob/preview/downloads-1.0.2/prefill-17.png)
