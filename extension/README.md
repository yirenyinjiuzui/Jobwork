# Chrome / Edge：保存公开岗位与辅助填表

1. 解压项目。Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 启用页面上的「开发者模式」，选择「加载已解压的扩展程序」，选中本项目的 `extension` 文件夹。如果之前加载的是旧项目，移除旧版并选择新版文件夹，避免工具栏出现两个相同功能的扩展。
3. 启动工作台后，到「资料与填表」页打开「本地练习表单」。点工具栏里的扩展，选择本文件夹的 `demo-profile.json`。
4. 点击「扫描当前网页」，预览字段、网址和拟填内容；勾选确认后点击「填写选中项」。练习表单中已有值的作品集地址不会被覆盖，毕业时间和工作许可保持空白。手动展开底部的模拟确认也不会发出资料。
5. 实际使用时，从工作台资料库导出你的 JSON，只在核对过域名的招聘页中加载；填好后回到网页检查、上传相应简历并自行提交。导出的资料 JSON 可能含姓名、邮箱等，别共享。

扩展只在你打开它操作时获得当前标签的临时权限；没有跨站或后台扫描权限。导入内容只驻留弹窗内存，关闭后需重新导入。不会处理密码、验证码、付款、附件上传或自动提交。即使未点提交，网页也可能根据输入实时保存或发送字段，因此只用于你信任的网页。

如果表单没有可读标签，可在弹窗粘贴手抄标签、工作台「图片文字识别」（可选本地 Tesseract）或外部 OCR 的结果（每行一个字段），查看建议后手动填写。不向识别不到的控件盲填；动态组件、内嵌表单等需要手动操作。

## 只识别当前输入框

先点击网页里的目标输入框，再打开浏览器助手、导入资料并点击「只识别当前输入框」。这可以用来逐个核对表单里出现的同名字段。预览会显示拟填值，勾选同意后才可填写。

扫描可识别「应聘者姓名」「电子邮箱地址」等简体标签。若一个区域只有一个输入框，且没有绑定标签，扫描可使用前方紧邻的可见独立标签。这类建议需要手动勾选。切换输入框或表单变化后，请重新扫描。

## 按条填写经历、获奖、证书和外语

从「资料与填表」保存资料并重新导出 JSON。在网申页使用「扫描当前网页」。扩展识别明确分组的教育、实习、工作、项目、校园经历，以及获奖、证书和外语能力。每类可见条数相同且顺序可核对时，才按网页顺序提出建议。不同条数、模板不明确或有异常编号时，先手动调整网页，再重新扫描。

预览会标出条次和拟填值。可以逐项勾选，也可以点「全选可选项」后逐项取消；改选后须重新确认填写授权。年月只匹配年月控件，已有值、证件号码、家庭信息和工作许可保持原状。展开「保留网页已有内容」可查看能唯一对应到同条资料的普通文本、文本域和年月是否与资料一致。比较在页面侧完成，扩展弹窗只收到一致或不同的结果。随包练习页及 `demo-profile.json` 包含上述各类的演示记录。

「资料与填表」中的「分条填表预览」可直接查看本地简体演示卡片。扩展弹窗也按资料类别及条次布局，字段和拟填值并排显示。

## 保存当前岗位为草稿

1. 先运行工作台，再在 Chrome 或 Edge 打开可信招聘官网的**单个公开岗位详情**。不要在登录、账号或个人申请进度页使用。
2. 点浏览器助手里的「识别当前岗位」。无需导入资料。优先读取岗位元数据，缺少时尝试公开岗位详情页的标题及可识别标签；显示「待补充」的字段留给你检查。
3. 核对岗位及来源链接后，点击「在工作台核对（不保存）」。工作台通常是端口 `8765`，如启动命令指定了别的端口，请在弹窗里改成同一个值。
4. 工作台只会带入岗位表单。修改并点击「录入岗位」才会记入岗位库。此流程不会打开申请表、提交简历或发送对外消息。来源地址默认移除查询参数和片段；满足招聘元数据匹配条件的公开 Greenhouse 岗位编号会保留。

部分网站不发布可识别的岗位元数据；列表页、浏览器拦截页或未识别出的岗位可到工作台手动录入。


## v1.1.3：确认只对本次扫描有效

扫描后请在两分钟内核对并填写。切页、切换标签、岗位或表单 DOM 变化后须重新扫描；即使 URL 没变，旧预览也可能失效。正常静止页面仍可填写。若填写第一项触发页面重建，扩展会停止剩余项，提示已写数量；先核对实际内容再重扫，不会转填新表单，也不会自动撤销已发生的输入。持续动态更新导致无法确认时，请手填。

会话仅在当前页面的扩展隔离世界内存暂存原节点引用和元数据；不保存资料字段值或值指纹，不添加主机权限。[测试层级与本地虚构夹具](../docs/PREFILL-BINDING.md)。Linux 实机扩展因 Chromium 启动环境限制未完成，Windows/Edge 工具栏仍待验收。


## v1.1.4：地点摘录

岗位草稿新增有限的地点相关原文与来源，供工作台区分实际实习、毕业后转正及异地培训。不会复制完整页面。核对后才保存；原地点不被推断值覆盖，缺失或冲突列入地点待复核。详见 [地点复核说明](../docs/LOCATION-REVIEW.md)。
原生单选下拉框支持性别、学历和政治面貌。工作台导出的 JSON 包含这三项中已保存的值；扩展预览显示网页实际选项。只有一个可用选项与资料对应时才会列为建议，已有选择保留。下拉建议需手动勾选并确认。自绘控件、多选、证件、家庭和工作许可留给用户处理。
