# 简历导入与个人资料

在本机解析简历、按条编辑教育和工作经历，通过「下一缺项」连续补齐资料并保存。

发布页中名称带 `profile` 的 ZIP 收录下面列出的源码、资料和测试。运行整个工作台请下载同版本的完整包。[查看发布版本](https://github.com/yirenyinjiuzui/Jobwork/releases)
