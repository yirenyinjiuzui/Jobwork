# 简历导入与个人资料

在本机解析简历、按条编辑教育和工作经历，通过「下一缺项」连续补齐资料并保存。

在「我的简历 → 审阅 Agent 资料建议」可粘贴一条邮箱、手机号码或目标岗位的修改建议。核对旧值和建议值，点击「采纳到草稿」，再点「保存资料」。旧值须与当前草稿一致。项目自带的岗位复核 Skill 可按此格式生成建议。

正式版下载页中名称带 `profile` 的 ZIP 收录下面列出的源码、资料和测试。运行整个工作台请下载同版本的完整包。[下载 1.0.2](https://github.com/yirenyinjiuzui/Jobwork/releases/tag/v1.0.2)
